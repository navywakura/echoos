# echOS 3.0.0 distribution

Built from the complete kernel source in this repository. The universal VM and metal filenames use the same kernel and common GRUB configuration. Both BIOS and UEFI QEMU boot checks passed CERT-21; receipts are in `docs/evidence`. These checks do not certify arbitrary physical hardware. AArch64 is supplied as a kernel image, separately from x86 ISO files.

Earlier reports retain their original hashes and are historical evidence. Current release checksums are supplied alongside the release assets.
