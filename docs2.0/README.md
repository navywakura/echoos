# echOS 2.1.0-honest — documentación

**Rogex Laboratories / Knights Labs · Roger Navarro · septiembre 2026**

Esto no es el `docs/` viejo. Aquel arrastra rxOS 4, 6, 9, EchOS 1.0 ECLIPSE,
los cuadernos del chatbot y mil papeles de laboratorio. Sigue ahí, no lo he
borrado.

`docs2.0/` es **solo la línea Universal CLI**: consola, Heap-0, un kernel.
2.1.0-honest es el corte donde la superficie (`help`, `epk list`, `man`)
coincide con el binario. Lo escribí para que alguien que no ha tocado el
árbol pueda entender qué es esto y qué *no* es.
